[IBM Db2 AI Vector Search](https://www.ibm.com/docs/en/db2/12.1?topic=db2-vector-search) stores embeddings directly in a Db2 table using the native `VECTOR(n, FLOAT32)` data type introduced in Db2 12.1.2. This lets you combine semantic similarity search over unstructured data with relational queries over your existing Db2 data in a single database.

### Requirements

- IBM Db2 12.1.2 or later with vector search enabled
- A Db2 user with `CREATE TABLE`, `INSERT`, `SELECT`, and `DELETE` privileges

```bash
pip install ibm_db
```

### Usage

<CodeGroup>
```python Python
import os
from mem0 import Memory

os.environ["OPENAI_API_KEY"] = "sk-xx"

config = {
    "vector_store": {
        "provider": "db2",
        "config": {
            "collection_name": "mem0",
            "embedding_model_dims": 1536,
            "connection_params": {
                "database": "MYDB",
                "host": "localhost",
                "port": 50000,
                "username": "db2user",
                "password": "your-password",
            },
        }
    }
}

m = Memory.from_config(config)
messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about sci-fi movies? They can be quite engaging."},
    {"role": "user", "content": "I love sci-fi movies, especially ones with space exploration."},
    {"role": "assistant", "content": "Got it! I'll remember you love sci-fi space exploration movies."}
]
m.add(messages, user_id="alice", metadata={"category": "movies"})
```
</CodeGroup>

To reuse a connection you already manage, pass it as `client`:

<CodeGroup>
```python Python
import ibm_db_dbi

conn = ibm_db_dbi.connect(
    "DATABASE=MYDB;hostname=localhost;port=50000;uid=db2user;pwd=your-password;",
    "",
    "",
)

config = {
    "vector_store": {
        "provider": "db2",
        "config": {
            "client": conn,
            "collection_name": "mem0",
            "embedding_model_dims": 1536,
        }
    }
}
```
</CodeGroup>

### Config

| Parameter | Description | Default |
| --- | --- | --- |
| `connection_params` | Dict with keys `database`, `host`, `port`, `username`, `password`. Optionally `security` (bool) and `ssl_cert` (path to `.arm`/`.pem` file). | `None` |
| `client` | An existing `ibm_db_dbi.Connection` to use instead of building one from `connection_params`. | `None` |
| `collection_name` | Name of the Db2 table that stores vectors and payloads. Created automatically if it does not exist. | `mem0` |
| `embedding_model_dims` | Dimension of your embedding vectors. Must be greater than 0. | `1536` |
| `distance_strategy` | Distance function used for search: `EUCLIDEAN`, `COSINE`, or `DOT`. | `EUCLIDEAN` |
| `text_field` | Column name for the raw text (`CLOB`). | `text` |
| `id_field` | Column name for the primary key (`CHAR(16)`). | `id` |
| `metadata_field` | Column name for JSON metadata (`BLOB`). | `metadata` |
| `embedding_field` | Column name for the stored vector. | `embedding` |

<Note>
  When you pass a pre-built `client`, Mem0 uses it as-is and will not close it on your behalf.
</Note>

### Search scores

Db2 returns a distance value from `VECTOR_DISTANCE`. Mem0 converts it to a similarity score where higher means more similar:

| Distance strategy | Conversion |
| --- | --- |
| `EUCLIDEAN` | `1 / (1 + distance)` → range `(0, 1]` |
| `COSINE` | `max(0, 1 - distance)` → range `[0, 1]` |
| `DOT` | returned as-is (higher inner product = more similar) |

### Metadata filters

Filters run against the JSON metadata column. Top-level keys are combined with `AND`. Values can be a scalar (equality), a list (IN match), or `"*"` (match any row where the field exists).

<CodeGroup>
```python Python
m.search(
    "movie recommendations",
    user_id="alice",
    filters={"category": "movies"},
)
```
</CodeGroup>
